# СЛМ — демо-концепция редизайна

Демонстрационная концепция редизайна сайта https://slm24.ru/ («Самая Лучшая Мебель», Красноярск).
**Не является официальным сайтом компании.** Контент (категории, цены, отзывы, контакты) взят с исходного сайта.

## Запуск
Откройте `index.html` или запустите `python3 -m http.server 8000` и зайдите на http://localhost:8000.

## Фотографии — ОБЯЗАТЕЛЬНЫЙ ШАГ
В архиве лежат только логотип и 4 фото категорий (кухни, шкафы-купе, детские, горка), вырезанные из скриншотов
(низкое разрешение). Остальные фото нужно скачать с исходного сайта командой:

    python3 tools/fetch_images.py

Скрипт сохранит: 22 фото шкафов-купе (`images/products/`), главный баннер (`images/banners/`),
фото остальных категорий (`images/cats/`), фото работ (`images/projects/` + `manifest.json`) и в конце напечатает,
чего получить не удалось. Пока фото нет, сайт показывает нейтральную заглушку с названием (это не фото).

## Структура папок images/
brand/ (логотип), cats/, products/, projects/, banners/

## GitHub Pages
Загрузите содержимое папки в корень репозитория (`index.html` в корне) и включите Pages: Settings → Pages → ветка `main`, `/ (root)`.
Пути относительные; внешние изображения не используются. Сначала запустите `fetch_images.py` и закоммитьте скачанные фото.

## Требует проверки владельцем контента
- Телефоны, адреса, почта, ссылки на Max/Telegram/VK/OK/2ГИС — взяты с slm24.ru, актуальность не подтверждена.
- Цены «от» и описания шкафов-купе — копия списка на slm24.ru; описания там обрезаны.
- Товары и цены остальных 10 категорий в проект не внесены (данные не получены).
- Условия скидки 15% и скидок для пенсионеров/новосёлов — со страниц исходного сайта, требуют подтверждения.
- Формы — демо: открывают письмо на dalshin@inbox.ru, заявки не отправляются.
- Фото категорий из скриншотов содержат водяной знак СЛМ и малы по размеру; по возможности замените оригиналами.
